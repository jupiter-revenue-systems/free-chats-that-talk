# Chats That Talk to Each Other

Split your work into named chats that hand off with an @-mention, so one finished job updates the others.

## The promise

When you finish, you'll have 3 or 4 named chats, each with one job, plus a note board they all read. You tell one chat the news. The others pick it up. No more repeating yourself.

## Who it's for

Coaches, agency owners and creators who use more than one AI chat and are tired of carrying messages between them.

## What's inside

- `GUIDE.md`: the full guide, step by step.
- `skill/handoff/SKILL.md`: the Handoff skill. It teaches Claude 3 phrases: "hand off to @Name", "check handoffs" and "close out".
- `INSTALL.md`: how to add the skill in Claude.ai, Claude Cowork and Claude Code.
- `templates/HANDOFFS.md`: the note board every chat reads and adds to.
- `templates/LANE_CARD.md`: the job description you paste into each chat.

## How to use it

1. Read `GUIDE.md`. It takes about 25 minutes to set up.
2. Pick 3 or 4 lanes (like Content, Site Edits, Ads) and make one named chat for each, plus one called Brain.
3. Paste `templates/LANE_CARD.md` into each chat with the blanks filled in.
4. Put `templates/HANDOFFS.md` in your shared brain folder, or in your Project files.
5. Install the skill with `INSTALL.md`.
6. In one chat say "hand off to @Content". In the Content chat say "check handoffs". If the news arrived, it works.

## What it doesn't do

- Nothing runs on its own. You still open each chat and say "check handoffs".
- It covers 3 or 4 chats, not your whole business.
- The chats pass notes. They don't check each other's work.
- Never put passwords, keys or card numbers in a handoff note. It's plain text.
